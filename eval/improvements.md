# 优化历程

记录对 Agent 系统可量化指标的每次改进。每次优化后运行 `python eval/run_eval.py <版本号>` 并 `--save-baseline` 存为新基线。

## 使用方式

```bash
# 1. 修正前跑一次基线
python eval/run_eval.py v1_before --save-baseline

# 2. 修改代码

# 3. 修改后跑一次对比
python eval/run_eval.py v1_after
# → 自动输出与 basline 的差异表格

# 4. 如果指标提升，更新基线
python eval/run_eval.py v1_final --save-baseline
```

## 实际记录

### #1 SSE 流式输出

**日期**：2026-05-20  
**问题**：Agent 同步阻塞，用户等待 5-10s 无反馈，工具调用黑盒  
**设计**：基于 `astream_events` 实现三级 SSE 事件流（text / tool_start / tool_end），首 token < 1s  
**影响**：

| 指标 | 优化前 | 优化后 | 变化 |
|------|--------|--------|------|
| 首 Token 延迟 | 5-10s | 2.2s (avg) | -56%~78% |
| 工具可见性 | 黑盒 | 三级事件推送 | 完全透明 |

**相关文件**：`api_server.py`
