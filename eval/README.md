# Agent 评估框架

## 使用方式

```bash
# 1. 先启动服务
python api_server.py

# 2. 新开终端，运行评估
python eval/run_eval.py
```

## 评估维度

| 维度 | 指标 |
|------|------|
| 工具准确率 | 期望工具是否被调用 |
| 关键词匹配率 | 回答中是否包含关键信息 |
| 首 Token 延迟 | 用户感知等待时间 |
| 总耗时 | 任务完成时间 |
| 错误率 | 请求出错比例 |

## 测试用例

`cases.json` 定义 12 个测试用例，覆盖：

- 天气查询 / 天气预报
- 公交路线 / 驾车路线
- POI 搜索 / 知识库检索
- 联网搜索 / 离线知识库
- 数学计算
- 带定位的路线查询
- 多工具协同（旅游规划）
- 多模式对比

## 输出

`report.json` — 详细的评估报告，包含：
- 全局指标（通过率、工具准确率、延迟分布）
- 分类指标（按功能模块拆分）
- 逐用例详情（每例的工具调用、关键词命中、耗时）
